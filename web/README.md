# Estampido · web

Interfaz web de Estampido: React 19, Vite 8, Tailwind CSS 4, shadcn/Radix, TanStack Query y Zustand.

```bash
npm --prefix web install
npm run dev          # desde la raíz: API :8787 + esta web en http://localhost:5173
npm --prefix web run build
npm --prefix web run lint
```

La documentación completa (características, arquitectura, despliegue) está en el [README principal](../README.md).
